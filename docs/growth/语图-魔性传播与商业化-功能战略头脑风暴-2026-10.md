## Round 0 · 三个战略前提（全部来自证据，非拍脑袋）

### 前提 1：传播介质必须是图片，不是链接

微信《外部链接内容管理规范》（2025-10 仍在更新）把「测试类 H5」列为违规类目、禁止诱导分享，且**无备案域名的链接在微信内天然不信任**。而**纯图片分享不含可点击外链，不在外链监管射程内**——朋友圈/群聊里图片的存活率远高于 H5 链接。

**结论：语图所有魔性功能的分享物必须是「一张自带回流的图片卡」（角标 + slogan + 生成入口文案），链接只做二级跳转。这恰好与无备案域名的现状兼容。**

### 前提 2：魔性传播的两种燃料，语图都要点

| 燃料 | 心理机制 | 案例 | 特点 |
|---|---|---|---|
| **自我表达型** | 「这是我」——晒关于自己的个性化结果，零社交风险 | 网易云年度报告、妙鸭写真、MBTI | K 因子极高，但一次性、无留存（妙鸭 2023 爆火 → 2025-09 团队解散） |
| **实用即内容型** | 「我很有用」——转发的图本身帮接收者省时间 | Gamma（作品分享即曝光，7000 万用户）、老照片修复前后对比 | K 因子中等，但带来的是**真实需求用户**，留存好 |

**结论：用自我表达型做获客前锋（拉 K 因子），用实用型做留存主力（接住流量）。每个魔性功能必须设计一座「通往编辑器的桥」，否则重蹈妙鸭覆辙。**

### 前提 3：一切新功能都是「X → FlowDraft → 图」引擎的新输入源

语图真正的资产不是流程图，是**中间结构 FlowDraft + 四级增量匹配 + 反思校验**。X 从 `一句话文本` 扩展为 `PDF / Word / URL / 代码仓库 / SQL / OpenAPI / git 数据`，引擎与编辑器全部复用。这也是相对 DeepWiki（静态 Wiki 图，不可编辑）、MyMap/NoteGPT（只有导图范式、无增量改图）的结构性差异。

### 3.2 如果只做三件事（未来 90 天的主赌注）

**赌注一：图片卡传播基建 + 「一图看懂」+「脑洞显影卡」（第 1-3 周）**
- 先建「分享卡工厂」：任意生成结果一键导出 3:4/1:1 精致图片卡（克制设计、角标 slogan、生成入口文案）——这是 A 层所有功能的公共地基，也是无备案域名下唯一可靠的传播介质。
- A1 与 A3 是纯引擎复用（新意图 + 新 Prompt + 卡片模板），零新基础设施。
- 度量：卡片导出量、图卡在社交平台的回流（分享页 `share_view`→`generate` 链路已可测，快赢批次一埋点直接复用）。

**赌注二：论文/Word → 技术路线图（第 2-6 周，赶 11-1 月开题季）**
- MinerU 解析 PDF/Word → 章节结构 → FlowDraft → 学术风路线图（新增一套学术主题，衔接 R8）→ 一句话增量改（引擎已有）。

## Round 4 · 红线与反面教训（照抄自证据，不是猜的）

1. **妙鸭教训——一次性爆款养不活产品**：每个 A 层功能的生成结果页必须放「继续编辑这张图」入口（通往编辑器的桥）；分享卡角标即回流入口。没有桥的魔性功能不做。
2. **CodeSee 教训——「看」不付费，「产出物」才付费**：repo→图必须绑定 README 图自动更新/文档同步这类持续产出，纯浏览必死。
3. **微信红线**：不做「分享后才能获得结果」；不做利益诱导分享；**不做测试类 H5**（A4 必须包装为「思维画像图工具」，题目无对错、结果无预测、不含运势命理）；不碰面相/算命/运势预测（清朗专项重点）。
4. **AI 双备案**：继续走 DashScope（已备案模型）路径；生成式 AI 服务登记在收费规模化前必须完成（launch plan 遗留项升级为硬阻塞）。
5. **成本闸门**：魔性功能 = LLM 成本放大器。A 层功能一律套用现有限流/额度体系（试用台账 + Token 三级防护 + 全局日限），年报类走「API 数据 + 模板渲染、LLM 只做文案」的低成本架构。
6. **隐私边界**：初期只处理公开数据（公开仓库、用户主动上传的文档）；聊天记录（A8）、私有仓库后置到合规与加密存储就绪之后。
7. **收回免费能力是雷区**（CapCut 教训，沿用上篇结论）：魔性免费层只加不减。
