## 四、差距分析：语图 vs 全场

**语图已具备的相对优势：**
1. **Agent 化深度**：意图路由→上下文组装→工具短路→生成→反思修正→人在回路→记忆体系，多数竞品只是「一次生成」；开源对标物 OpenDiagram 与语图同哲学（LLM 出语义结构、程序化布局）。
2. **免登录试用 + 场景工厂 SEO + 增长埋点**：国际竞品普遍要注册（Excalidraw 除外）。
3. **多形态产物（刚上线）**：表格/清单/时间线已超过多数「只做图」的竞品，接近 Napkin 的多形态叙事。

**关键差距（按影响排序）：**

| # | 差距 | 对标 | 机会 |
|---|---|---|---|
| G1 | **无 DSL 导入**：粘贴 Mermaid/PlantUML 无法变图（导出已有 toMermaid util） | Mermaid 生态 70k★、Excalidraw「AI 先转 Mermaid」 | 接入 Mermaid 导入 = 免费获得存量内容生态（用户把旧 Mermaid 资产搬进来） |
| G2 | **无文档/长文入口到新形态**：digest 页只出图 | Mermaid AI 拖文档、WPS AI 文档提炼 | 长文→思维导图/清单/时间线（digest × artifacts 组合） |
| G3 | **一次只出一版一形态**：无多方案挑选 | Napkin 多方案 | 「换一种形态」一键重生成（formHint 已具备底层能力） |
| G4 | **无版本历史**：生成不满意回不去 | OpenDiagram/Whimsical 路线图 | 会话内上一版/下一版 |
| G5 | **无追问引导**：生成后冷场 | 竞品普遍有 next-step 建议 | suggest 纯函数建议 chips |
| G6 | **新形态无法带走为文件**：仅剪贴板 Markdown | Napkin PNG/SVG/PDF/PPT | .md 文件下载（.md 可进 Notion/Obsidian/GitHub） |
| G7 | **模板仅流程图**：16 个后端模板不覆盖新形态 | ProcessOn/亿图模板生态 | 4 形态模板短路（零 token 秒回）+ 模板中心展示 |
| G8 | **形式路由无观测**：新形态质量黑盒 | — | trace FORM_ROUTE 埋点 |
| G9 | **决策场景深度不足**：对比表只呈现不打分 | 无竞品做（差异化机会） | 维度加权打分 |
| G10 | 自托管/BYOK 缺失 | OpenDiagram/ai-draw | 暂缓（SaaS 商业化优先，不跟进） |

## 五、结论：二十轮演进主线

`docs/specs/competitor-driven-evolution-batch/spec.md` 按五条主线落地上述差距：
**A. DSL 互操作**（G1：Mermaid/PlantUML 导入解析 + 导入 UI）→ **B. 产物深度**（G9/G5：加权打分、自然时间排序、追问建议、表格行内编辑）→ **C. 产物可携带**（G6/G4/G3：文件下载、版本历史、本地草稿箱）→ **D. Agent 智能深化**（G7/G8：artifact 模板短路、路由观测、会话形态偏好、注入对抗）→ **E. 场景增长**（G2/G7：新形态场景页、模板中心扩展、试用引导）。
