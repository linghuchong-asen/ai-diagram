# 增长运营一页纸（零预算 · 首周执行版）

> 适用：`bootstrap-growth-and-monetize` spec / Task 8.3
> 原则：只宣传当前已实现能力；所有动作当天可执行、零投放；产品缺口统一列在末尾「待确认」。

## 0. 一句话定位与本周唯一目标

**定位**：语图 Yutu —— 一句话生成流程图的免登录网页工具，免费试用、按次解锁高清无水印。

**目标用户**：有轻量流程图需求的学生（毕设答辩、课程作业、学习路径）与职场人（请假、报销、入职、审批、电商售后、研发流程）。他们不常画图、不愿学专业工具、需要 30 秒出结果。

**本周唯一目标**：完成一次真实渠道冷启动，验证「匿名试用 → 注册 → 分享 → 付费」链路能跑通。以 **100 张/周生成量** 作为首周验证目标（假设值），不以收入为本周硬指标。

**本周不做**：付费投放、订阅制、App/小程序、画布编辑器大改。

## 1. 北极星指标：周生成图数

- **口径**：近 7 天 `generate` 事件总数，含匿名与注册；一次成功出图记 1（真实 LLM 与模板兜底都算），失败/挂起不算。
- **埋点字段**：`event=generate`、`userId`、`anon`、`trialId`、`threadId`、`intent`、`mode`（`real` / `template`）、`tokens`。
- **拆分观察**：匿名 `anon=true`；注册 `anon=false`；匿名去重 `trialId`；注册去重 `userId`。
- **首周目标**：**验证 100 张/周**（假设值，建议区间 80–150，按渠道实际量调整，不作为对外承诺）。第二周若注册转化 ≥10%，再提高到 200 张/周。

```bash
# 日志目录按 UTC 日期分目录；跨天取数必须用 date -u
LOGDIR=/root/.cache/yutu-runtime/logs
for i in $(seq 0 6); do
  cat "$LOGDIR/$(date -u -d "-$i day" +%F)/info.log" 2>/dev/null
done > /tmp/growth-7d.log

grep -c 'GROWTH_EVENT.*"event":"generate"' /tmp/growth-7d.log          # 周生成图数
grep -c 'GROWTH_EVENT.*"event":"generate".*"anon":true' /tmp/growth-7d.log   # 匿名生成
grep -c 'GROWTH_EVENT.*"event":"generate".*"anon":false' /tmp/growth-7d.log  # 注册生成
grep '"event":"generate".*"anon":true' /tmp/growth-7d.log \
  | grep -o '"trialId":"[^"]*"' | sort -u | wc -l                       # 去重匿名试用身份
```

> 备选：`docker logs --since 168h yutu-backend 2>&1 | grep -c '"event":"generate"'`。不要用宿主机 `date +%F` 拼日志目录——宿主机是 Asia/Shanghai，与日志 UTC 目录会差一天。

## 2. 漏斗定义与目标转化率假设

> 以下转化率均为**待验证假设**，首周只看方向，不作考核承诺。当前 `register` 事件不带 `trialId`，无法把某次匿名试用精确归因到某次注册，下表按同周聚合近似。

| 层级 | 分子 | 分母 | 当前埋点字段 | 首周目标（假设） | 干预动作 |
|---|---|---|---|---|---|
| 试用 | `generate` 且 `anon=true` 的次数 / 去重 `trialId` | 无（漏斗起点，用绝对数） | `event`、`anon`、`trialId`、`mode` | ≥60 个独立试用身份/周 | 首页大输入框 + 3 个快捷 chips；群内发「免登录 30 秒」样例；发群前确认全站试用额度没被打满 |
| 注册 | `register` 次数 | 同周去重匿名 `trialId` 数 | `event`、`userId`、`username` | ≥10% | 第二次生成触发注册引导卡；应用画布后提示「注册登录后可保存并继续编辑」；强调「作品保留 + 每日 3 次 + 分享再 +1」 |
| 分享 | `share_create` 次数（仅新建 token，幂等复用不计） | 同周 `register` 次数（链路口径）；运营主口径改用「当周有生成行为的注册用户数」 | `event`、`userId`、`projectId` | 链路口径 ≥15%；主口径 ≥10% | 生成成功后直接引导分享；明确「首次分享 +1 次，日上限 +3」；用 3 个不同项目凑满 +3 |
| 付费解锁 | `unlock_pay` 次数（支付回调成功才记） | 同周 `share_create` 次数（链路观察）；主口径 = 当周注册生成用户数 | `event`、`userId`、`projectId`、`orderId`、`amount` | 链路 ≥5%；主口径 1%–3% | 预览页「解锁高清导出」按钮；话术锚定 ¥1.9/张、永久去水印；通道未配置时按赞助话术承接 |

**口径提醒**

- `share_create` 只在「首次新建分享 token」时记录；同一项目重复分享复用 token，不记事件、不发奖励。
- `unlock_pay` 只在支付回调验签成功、订单置 `paid` 时记录；创建订单不记。支付通道未配置时该事件恒为 0，不能据此判断「用户不愿付费」。
- 当前没有页面浏览、CTA 点击、试用发起埋点；「分享页浏览 → 注册」无法从埋点得出，只能看 `share_create`，必要时用 Nginx access log 做代理指标（格式待确认）。

## 3. 获客引擎 A：免登录试用（拉新主入口）

**入口（当前实现）**

- 首页大输入框：输入一句话 → `/trial?q=...`，浮窗自动发送，约 30 秒出图。
- 直达 `/trial`；模板中心卡片 → `/trial?q=<模板 prompt>`。
- 匿名可生成并「应用到画布」，作品暂存本地；注册登录后首页出现「继续你的试用作品」提示条，可一键新建项目继承。

**为什么愿意点（当前页面文案）**

- 主标题：**一句话，生成你的流程图**
- 副标题：**免登录免费试一次 · 约 30 秒出图 · 注册后每日 3 次**
- 异议消除：不用下载、不用注册、手机能开；先看效果，满意再注册保存。

**发哪里（零预算，首周聚焦）**

- 校园 QQ 群/微信群：毕设群、课程作业群、考研复试群。先答 1–2 个问题，再发链接。
- 百度贴吧：毕设吧、流程图吧、大学生吧。发经验帖，不刷屏。
- 小红书/知乎：发「毕设流程图怎么做」前后对比，正文放试用入口。
- 同一群 24 小时最多 1 次；每条内容只放 1 个主链接。

**单次限制 → 注册动机（当前实现；2026-10-26 快赢批次一起额度由 1 次/日上调为 2 次/日，依据 Gamma 激活教训——访客第二次输入通常是修正第一次结果，须让 aha 完整发生）**

- 同一匿名 `trialId` 每日 **2 次**（env `AI_TRIAL_PER_ID_PER_DAY` 可覆盖）；同 IP 每日 **6** 次；全站默认 100 次/日（`AI_TRIAL_DAILY_GLOBAL_LIMIT` 可调）；另有同 IP 10 分钟 5 次限流。

- 只讲事实：注册后每日 3 次免费生成，首次分享再 +1（日上限 +3）；不承诺无限免费。

## 5.5 获客引擎 D：邀请裂变（用户自驱拉新，2026-10-27 新增）

**机制（必须说准确，口径与后端 `billing/invite.ts` 一致）**

- 每个用户注册即有专属 8 位邀请码（`/invite` 页可查、可一键复制链接 `${origin}/register?ic=<码>`；存量用户首次访问懒生成）。
- **邀请人**：每成功邀请 1 位新用户注册，会员有效期 **+1 天**（未开通 = 获得当天起 1 天体验会员，直接享受全站免水印 + 每日 30 次额度）；**单日上限 +3 天**（防小号）。
- **被邀请人**：注册当日生成额度 **+2 次**（欢迎礼，与分享奖励同池叠加）。
- 非法/不存在的邀请码静默忽略，注册永不因此失败；自邀请无收益（同账号防御）。

**为什么愿意发（动机设计）**

- 旧模式：用户把产品链接发群 = 无私奉献；新模式：发自己的邀请链接 = 每次转化给自己攒会员天数。会员既是奖励又是付费权益——裂变与商业化互相放大。
- 被邀请人先得 +2 次生成（aha 更容易完整发生），注册转化率预期高于冷邀请。
- **阶梯里程碑（留存与裂变加强批次）**：累计邀请 3 人额外 +3 天会员、累计 10 人额外 +7 天会员（自动发放，每档一次）——给重度分享者一个可规划的冲榜目标，话术从「邀请有奖」升级为「邀请冲榜」。进度在 `/invite` 页可视。

**怎么用（渠道打法不变，链接升级）**

- 把第 3/4/5 节所有「发链接」动作的链接统一换成个人邀请链接（`/invite` 页复制）。
- 群话术示例：「我最近在用这个一句话生成流程图的工具，用我的邀请码注册你多送 2 次生成：<链接>」——先给对方好处，再谈自己得什么。
- 邀请页本身可截图传播（邀请码 + 战果卡片），配文案「已邀请 N 人，会员天数涨到 X」。

**埋点与复盘**

- 后端 `invite_register` GROWTH_EVENT（inviterId/inviteeId/inviterRewarded）→ 漏斗「邀请 → 注册」可测。
- 营收看板新增「累计邀请注册」卡片；`register` 埋点的 channel 与邀请归因相互独立（channel 管渠道、ic 管个人）。
- 异常阈值：单人单日邀请注册 >3 视为正常封顶；邀请注册占比 >50% 警惕小号刷奖励（配合注册 IP 限流观察）。

**合规红线（延续 §8）**

- 自愿激励，无「不邀请不能用」类强制话术；不承诺「邀请必得现金」；防刷靠注册 IP 限流 + 日上限，发现小号批量注册立即核查。

## 5.6 留存引擎：每日签到（2026-10-27 新增）

**机制（口径与后端 `ai/checkin/checkin.service.ts` 一致）**

- AI 浮窗配额栏每日签到：**当日生成额度 +1**（与分享/邀请奖励同池，日总额度封顶逻辑同 bonus_generate）。
- **连续签到每满 7 天的整数倍：会员有效期 +1 天**（自动发放）——免费用户在付费决策前先体验会员权益（全站免水印 + 每日 30 次），体验即转化。
- 断签重置连签计数（不设补签，保持「连续」的稀缺感）；当日重复签到幂等。

**为什么有效（动机设计）**

- 签到把「想画图」从一次性需求变成每日回访理由；连签 7 天的会员奖励给用户一个「留下来」的具体理由。
- 会员体验期结束前的最后一天是天然付费触点——到期当日额度回落 3 次/日，落差感就是转化窗口（可配合到期提醒文案，另批）。

**运营动作**

- 群话术补充：「注册后每天来签到，连签 7 天送 1 天会员」——与邀请裂变组合成「每日签到 + 邀请冲榜」双钩子。
- 复盘口径：签到率（签到用户/日活）、连签 7 天达成率、签到用户次周留存 vs 非签到用户（`GROWTH_EVENT checkin_vip` + daily_checkin 表可查）。

## 6. 付费转化（按次解锁 + 会员月卡）

**定价锚点（服务端配置）**

- 按次解锁：默认 **190 分 = ¥1.90/张**；`UNLOCK_PRICE_FEN` 可覆盖，前端按订单金额显示 `¥1.9`；首单 **90 分 = ¥0.90**（`FIRST_UNLOCK_PRICE_FEN`）。一次性解锁，项目后续修改再导出仍无水印（`unlocked` 持久）。
- **会员月卡（商业化闭环批次新增）**：**990 分 = ¥9.9/月**（`VIP_MONTH_PRICE_FEN`），首月特惠 **590 分 = ¥5.9**（`VIP_MONTH_FIRST_PRICE_FEN`）。权益：**每日 30 次生成**（`VIP_DAILY_GENERATE_LIMIT`）+ **全站导出/分享免水印**（名下所有项目 `unlocked` 服务端直接下发 true）。续费叠加：在期内续费从现有到期时间顺延 30 天，不丢剩余天数。
- 金额只信服务端，前端不传价；对外统一话术：「免费版带水印；¥1.9 解锁单张永久无水印，¥9.9/月会员全站无水印 + 每日 30 次。」

**免费 → 付费触点（当前实现）**

- 预览页工具栏「解锁高清导出」；未解锁时导出 PNG/SVG 带水印；已解锁显示「已解锁」（会员显示「会员·已解锁」+ 到期日）。
- **导出水印预览确认（付费转化增强批次）**：未解锁用户点导出先看「导出预览」弹窗（水印效果 + ¥1.9 去水印 CTA），免费导出能力保留、价值感知前置。
- **公开价格页 `/pricing`（付费转化增强批次）**：免费/单图/会员三卡对比，访客不登录也能看到完整价格锚点；首页/分享页/解锁弹窗均有入口。
- 解锁弹窗双 SKU：单图解锁动线内嵌会员交叉销售（「更划算：会员月卡 ¥9.9/月」）；会员单与解锁单同一支付/轮询动线。
- **支付回跳页（商业化闭环批次新增）**：支付完成落地 `/unlock-result`（此前 404 的硬伤已修复），轮询确认后跳回预览页/首页。
- 分享页：**owner 打开自己的分享链接 → 顶栏「解锁高清导出」直达预览页**（变现最短路径）；未解锁访客底部前置「免费版带水印，¥1.9 解锁高清无水印」价值主张。
- 免费水印：「语图 Yutu · 一句话生成流程图」+「免费版」，右下角、低对比度。

**未配置真实支付通道时（当前降级 + 沙箱）**

- 缺少 `XUNHU_APP_ID` / `XUNHU_APP_SECRET` 任一时，后端返回 `mode:'sponsor'`，不报错、不阻断。前端弹窗显示价格与联系邮箱（占位符 `support@yutu.app`，上线前必须替换）。

## 8. 风险与合规红线

- **收款**：个人收款码不得用于自动化解锁；自动解锁只能走已验签的支付回调。赞助模式当前只展示引导、不自动放行；不得凭转账截图手动批量改库。
- **刷量**：禁止自注册、脚本刷 `generate`、重复分享同一项目骗奖励。分享奖励仅首次新建 token，日上限 +3，幂等复用不奖励。
- **诱导分享**：不写「不转发不能解锁」「集赞解锁」「转发 3 个群才给额度」；分享奖励是自愿激励，不使用强制/利诱违规话术。
- **隐私**：分享页只回传项目名 + 画布 JSON，不含 `userId`；未经同意不公开用户原图、提示词、账号信息；撤销分享会物理删除 token。案例截图先打码或取得同意。
- **内容**：不生成/传播违法、侵权、涉密流程；发现违规内容立即停止分享并删除。
- **数据**：`GROWTH_EVENT` 含 `userId`/`trialId`，仅运营本人可读，不对外导出个人标识。
- **平台规则**：进群先看群规，先答疑后发链接；不刷屏、不私信骚扰；小红书/知乎外链遵守平台规则。
